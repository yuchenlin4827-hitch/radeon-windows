Radeon Open KMD (rokmd) — 安装说明（测试版 / Alpha）
======================================================

一、适用硬件（AMD TeraScale 系列，PCI 供应商 ID VEN_1002）
----------------------------------------------------------
  移动系列（Seymour/Caicos，0x6760-0x677B）：
      HD 6490M（Seymour XT，0x6768；部分机型为 Caicos 0x6766/0x6767）、
      HD 7470M（Caicos XT，0x6778）、
      HD 6400M / 6430M / 6470M / 6450A / 7450A / 7470 / 8470 等
  Llano APU 内显（Sumo/SuperSumo，0x9640-0x964F）：
      HD 6380G / 6410D / 6480G / 6520G / 6550D / 6620G 等
  桌面独显（TeraScale 1/2/3 全家族，INF 共覆盖 300+ 设备 ID）：
      HD 4800（RV770）/ HD 5770（Juniper）/ HD 6850-6870（Barts）/ HD 6970（Cayman）
      以及 HD 2000-4000 / HD 5000 / HD 6400-6900 全系列

  不确定自己的卡？先运行 tools\gpu_probe.exe，它会列出
  PCI 供应商/设备 ID、当前驱动与 Vulkan 状态，然后对照 rokmd.inf 的支持表。

二、包内容
----------------------------------------------------------
  bin\rokmd.sys          内核模式驱动（WDDM 2.0，Release x64，嵌入测试签名）
  bin\rokmd.pdb          调试符号（配合 WinDbg 使用）
  rokmd.inf              设备信息文件（TeraScale 全家族 PCI ID 表，
                         stampinf 展开产物，UTF-16LE 编码）
  rokmd.cat              目录签名文件（覆盖 INF 与 sys；v0.2.4-alpha 起随包提供）
  rokmd-testsigning.cer  测试签名证书公钥（CI 每次构建重新生成，导入后本机信任）
  tools\gpu_probe.exe    硬件探测工具（用户态，MSVC 构建）
  tools\install-rokmd.ps1  一键安装 / 卸载脚本（见第三节）
  LICENSE                MIT 许可证

  ⚠️ v0.2.3-alpha 及更早的包没有 rokmd.cat 与证书 —— pnputil 必然报
  "The third-party INF does not contain digital signature information"，
  请换用 v0.2.4-alpha 及以上的包。

三、安装步骤（Windows 10/11 x64，需管理员权限；测试签名三前提）
----------------------------------------------------------
  本驱动未经微软 WHQL 认证，走「测试签名」路径。三个前提缺一不可：

  1. 关闭 Secure Boot（UEFI 固件设置里关）。开着时 bcdedit 会报
     "The value is protected by Secure Boot policy"，testsigning 开不了。

  2. 关闭内存完整性（HVCI）：
     Windows 安全中心 → 设备安全性 → 内核隔离 → 内存完整性 = 关。
     开着时测试签名内核驱动会被 Code Integrity 拦截（0xC0000428）。

  3. 开启测试签名模式并重启：

       bcdedit /set testsigning on

     重启后桌面右下角出现「测试模式」水印即生效。

  4. 一键安装（推荐；自动导入证书 + pnputil）：

       powershell -ExecutionPolicy Bypass -File tools\install-rokmd.ps1

     脚本会：检查上述三前提 → 清理并导入 rokmd-testsigning.cer 到
     LocalMachine\Root 与 TrustedPublisher → pnputil /add-driver rokmd.inf /install。
     刚开 testsigning 时脚本会提示先重启、再重跑一次。

     手动等价操作：
       Import-Certificate -FilePath .\rokmd-testsigning.cer `
         -CertStoreLocation Cert:\LocalMachine\Root
       Import-Certificate -FilePath .\rokmd-testsigning.cer `
         -CertStoreLocation Cert:\LocalMachine\TrustedPublisher
       pnputil /add-driver rokmd.inf /install

  5. 验证：
       pnputil /enum-drivers          （应能看到 rokmd.inf）
       设备管理器中该显卡应显示 "Radeon Open KMD (...)"。
       tools\gpu_probe.exe 可核对 PCI ID 与（安装后）escape 通道状态。

  6.（可选）虚拟机实验：QEMU/Hyper-V/VirtualBox/VMware 中的模拟显示设备
     （如 QEMU -device ati-vga，1002:5046）会安装到独立的"SIMULATED"驱动
     实例，强制模拟模式跑通 WDDM 管线，不触碰真实硬件。
     详见仓库 docs/simulated-device.md。

  7.（可选，M3.4a）CP ring bring-up 实验（默认关闭，未开启时驱动对
     硬件零写入）：

       reg add "<驱动键>\Parameters" /v EnableRing /t REG_DWORD /d 1 /f

     重启生效后，驱动会执行 Evergreen CP 初始化序列（微码写入/软复位/
     ring 编程/ME_INIT/scratch 回环测试）。用 gpu_probe.exe [4.11] 段
     观测：`ring bring-up: PASS` 即 CP 已从 ring 取指。风险与边界见
     仓库 docs/bringup-safety.md 第 3.5 节。

四、探测工具输出说明（v0.2.3）
----------------------------------------------------------
  [1.7] PCI memory resources：用户态即可读到的 BAR 形态 —— TeraScale 卡
        预期 BAR0 = VRAM 孔径（>16MB）、BAR2 = MMIO 寄存器窗口（256-512KB）。
  [4.11] QUERY_HW_STATUS：装了 rokmd 后的只读寄存器快照（VRAM/FB 地址/
        GRBM/SRBM/CP 状态/ring test 结果）；非 rokmd 适配器报 0xC0000001
        系错误属预期。

五、卸载
----------------------------------------------------------
       powershell -ExecutionPolicy Bypass -File tools\install-rokmd.ps1 -Uninstall

     或手动：
       pnputil /enum-drivers          （找到 oemXX.inf 对应 rokmd）
       pnputil /delete-driver oemXX.inf /uninstall
  恢复正常签名模式：bcdedit /set testsigning off 后重启。
  测试证书可留可删：certmgr.msc → 受信任的根证书颁发机构 / 受信任人
  里删 "Radeon Open KMD Test Signing"。

六、注意事项与排错（症状 → 原因 → 处理）
----------------------------------------------------------
  - pnputil 报 "The third-party INF does not contain digital signature
    information"：
      包内缺 rokmd.cat（≤v0.2.3-alpha 的包）/ 证书未导入 / 未进测试模式。
      → 换 v0.2.4-alpha+ 的包；确认两条 Import-Certificate 无报错；
      确认「测试模式」水印已出现。
  - bcdedit 报 "The value is protected by Secure Boot policy"：
      Secure Boot 未关 → 进 UEFI 固件设置关闭后重试。
  - 驱动包装上了，但设备黄色叹号 / 错误代码 52 / 0xC0000428：
      内存完整性（HVCI）开着 → 关闭后重启。
  - 设备仍显示"Microsoft 基本显示适配器"：
      看 C:\Windows\INF\setupapi.dev.log（搜 rokmd）定位具体错误；
      事件查看器 → Microsoft-Windows-CodeIntegrity/Operational 看签名拦截。
  - 屏幕黑掉 / 无输出：
      render-only 驱动接管唯一显示 GPU 的已知风险 → 进安全模式执行卸载
      （WinRE → 疑难解答 → 启动设置 → 安全模式）。

  - 当前版本为 M3.4a：M2 全量 WDDM 2.0 DDI/escape/模拟设备 + CP 微码
    内嵌与 ring 初始化观测路径（默认关闭）；尚不具备真实渲染能力；
    真实 ring 提交是 M3.4b，UMD（terakan Vulkan）接入是 M4 里程碑。
    详见 docs/roadmap.md。
  - 请勿在生产环境使用；实验环境建议先做系统还原点。
